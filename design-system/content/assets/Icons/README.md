The Hugeicons free (stroke-rounded) icons the library itself imports: shell chrome, theme switcher, notifications, password visibility, passkeys and code samples. 24×24 grid, 1.5px stroke, round caps.

In the product they draw in `currentColor` through `HugeiconsIcon`, usually at 16px. These preview files are inked in `eclipse` (`#18181b`) because an `<img>` cannot inherit colour; in code use the icon from `@hugeicons/core-free-icons` so it takes its text token.
