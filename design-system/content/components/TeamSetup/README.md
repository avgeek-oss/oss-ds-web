# TeamSetup

Two-step first-run onboarding: account details, then date and time preferences.

**Use for** creating the team and its first administrator, once per installation.

**Provide** `brand`, `preferenceOptions`, optional `initialPreferences`, and one awaited `onSubmit` that verifies the `setupSecret`. Preview mark is a stand-in.

**Don't** change the standard copy or restyle headings and buttons.
