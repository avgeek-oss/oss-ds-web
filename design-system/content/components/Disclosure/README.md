# Disclosure

One collapsible section under a full-width trigger.

**Use for** optional detail such as advanced options. Use `Accordion` for several sections, `Tabs` for peer views.

**Props** `isExpanded` / `onExpandedChange` or `defaultExpanded`; parts `Heading`, `Trigger`, `Indicator`, `Content`, `Body`.

**Don't** add app padding or alignment overrides.
