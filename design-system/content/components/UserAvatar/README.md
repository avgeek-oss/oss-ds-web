# UserAvatar

A person's avatar from an email: initials plus a Gravatar lookup.

**Use for** people, workspace members and the account menu. Use `Avatar` for non-person entities.

**Props** `email`, optional `name` (initials and accessible name), optional `src` to skip Gravatar, plus Avatar props.

**Don't** add a separate Appearance setting; `ProfileImageSettings` manages the image.
