# Chip

Single-line label for status, category or count.

**Use for** short metadata in rows, cards and headers. For a domain status with an icon and tooltip, use `StatusIndicator`.

**Props** `color` default · accent · success · warning · danger; `variant` soft · primary · secondary · tertiary; `size` sm · md · lg.

**Don't** wrap or restyle chips in an app; keep labels to one or two words.
