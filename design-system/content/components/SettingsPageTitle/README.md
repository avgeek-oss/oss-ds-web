# SettingsPageTitle

The standard title and 19px icon for a common settings page, matching secondary sidebar entity headings.

**Use for** `titleContent` on Account and Team settings pages.

**Props** `section`: `profile` · `preferences` · `sessions` · `api-keys` · `mcp-connections` · `mcp` · `people` · `members` · `general`.

**Don't** pass a custom title or icon for a common section.
