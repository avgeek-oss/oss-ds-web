# ComboBox

Editable input that filters a list as people type.

**Use for** long lists where people may type the value, such as time zones. Use `Select` for short lists, `Autocomplete` for a non-editable trigger.

**Props** `selectedKey` / `onSelectionChange`, `inputValue` / `onInputChange`, `variant` primary · secondary; parts `InputGroup`, `Trigger`, `Popover`.

**Don't** shrink the input below 16px on mobile.
