# Input

The HeroUI single-line text input, re-exported unchanged.

**Use for** free text: names, emails, URLs, numbers. Use `PasswordInput`, `Textarea`, `InputGroup` or a picker for those cases.

**Props** native input attributes and an accessible name; `variant` primary · secondary (inside widgets, modals, drawers); `fullWidth`.

**Don't** override the font size; text entry stays 16px on mobile.
