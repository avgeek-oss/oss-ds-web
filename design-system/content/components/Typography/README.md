# Typography

Text primitives mapped to the shared type scale.

**Use for** content text in patterns and pages. Page titles come from `ApplicationPage`.

**Props** `TypographyHeading level` 1–6; `TypographyParagraph size`, `weight`; `TypographyText textRole`; `color` default · muted · danger; `TypographyCode`.

**Don't** set raw font sizes or colors.
