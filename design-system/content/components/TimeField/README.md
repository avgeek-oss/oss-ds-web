# TimeField

Segmented time input.

**Use for** standalone times of day. Use `DateTimeRangePicker` for date-and-time intervals.

**Props** `value`/`defaultValue` (`Time`), `onChange`; `hourCycle` 12 · 24; `granularity`; `isDisabled`; group `variant` primary · secondary.

**Don't** store display formats; apps own time zones and UTC.
