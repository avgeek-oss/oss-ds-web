# Button

HeroUI button for in-page actions; `ButtonLink` for navigation.

**Use for** actions. Use `AsyncActionButton` when the action awaits a request.

**Props** `variant` primary · secondary · tertiary · ghost · outline · danger · danger-soft; `size` sm · md · lg; `isDisabled`, `isIconOnly`.

**Don't** make Cancel a second primary; use `secondary`. Icon-only buttons need an `aria-label`.
