# DateRangePicker

Start and end date inputs with a range calendar popover.

**Use for** a date-only interval, such as a reporting period. Use `DateTimeRangePicker` when times are included.

**Props** `value` / `onChange` `{ start, end }`, `minValue` / `maxValue`, group `variant`; label both inputs and the trigger.

**Don't** expect it to validate retention limits; the app owns that.
