# Accordion

Collapsible content sections, in default or surface variants.

**Use for** FAQs or grouped help. Use `ExpandableAttributeList` for label/value rows, `Disclosure` for one region.

**Props** `variant` default · surface; `defaultExpandedKeys` or `expandedKeys` + `onExpandedChange`; `allowsMultipleExpanded`.

**Don't** hide required fields or primary actions in collapsed sections.
