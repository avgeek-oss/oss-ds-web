# DatePicker

Segmented date field with a calendar popover.

**Use for** calendar entry of one date. Use `DateField` for typed entry, `DateRangePicker` for intervals.

**Props** `value` / `onChange` (`CalendarDate`), `minValue` / `maxValue`, `isInvalid`; group `variant` primary · secondary.

**Don't** build a separate popover calendar; compose this one.
