# HeadingHelp

A help icon beside a page or widget heading that opens a description and documentation link.

**Use for** attaching docs to a heading, directly or app-wide through `HeadingHelpContext`.

**Props** `title`, `kind` (`page` · `widget`), `help` (`{ description, href, linkLabel? }`, or `false`).

**Don't** use it for field hints; use the field `Description`.
