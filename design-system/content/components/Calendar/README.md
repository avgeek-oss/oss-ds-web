# Calendar

Inline month calendar for one date.

**Use for** an always-visible calendar. Use `DatePicker` for a field, `RangeCalendar` for intervals.

**Props** `value` / `onChange` (`CalendarDate`), `aria-label`, `minValue` / `maxValue`, `isDateUnavailable`; parts `Header`, `Grid`, `Cell`.

**Don't** restyle cells per app.
