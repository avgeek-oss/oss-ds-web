# Switch

On/off switch for settings that apply immediately.

**Use for** preferences such as notifications. Use `Checkbox` for form options and `ToggleButton` for view controls.

**Props** `isSelected`/`defaultSelected`, `onChange`; `size` sm · md · lg; `isDisabled`; a `Label` or `aria-label`.

**Don't** label a switch with a question; name the setting.
