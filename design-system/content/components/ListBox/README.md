# ListBox

The HeroUI selectable list used inside pickers or inline.

**Use for** `Select`, `ComboBox` and `Autocomplete` popovers, or an inline selection. Use `Dropdown` for actions.

**Props** `ListBox.Item` (`id`, `textValue`, `ListBox.ItemIndicator`); `selectionMode` single · multiple; `selectedKeys`, `onSelectionChange`.

**Don't** place metadata over the selection tick.
