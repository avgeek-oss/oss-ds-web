# Tabs

Switches between peer views of one object on the same page.

**Use for** views such as Overview, Deployments and Logs. Use `SecondaryItems` for page navigation and `Disclosure` for optional detail.

**Props** `selectedKey`/`defaultSelectedKey`, `onSelectionChange`, `orientation`; parts `List` (`aria-label`), `Tab`, `Indicator`, `Panel`.

**Don't** restyle the tab list or indicator.
